# 페이지 구성과 전환

사용자 승인 범위: 설정으로 구성하는 페이지, 수동 선택·고정, 활성 앱에 따른 자동 선택, 페이지 전환 페이드. 현재 홈 세션 보드와 잠금·종료 대기화면 계약을 유지한다.

## 구성

- `PageBoard`: 페이지 정의와 앱 조건을 읽어 현재 페이지를 선택한다. 각 페이지의 신호 목록은 기존 `SessionDeck`을 사용한다. 목록 내부 페이지 번호와 사용자 페이지 ID는 별개다.
- `ApplicationContext`: macOS 활성 앱 bundle ID를 읽기 전용으로 관측한다. 창 제목·모니터·프로젝트는 이번 단계에서 수집하지 않는다.
- `streamdeck.board`: 기본 페이지, 페이지별 필터·고정 버튼, 전환 효과 설정이다. 설정이 없으면 기존 보드를 그대로 표시한다.
- `HidDisplay`: 목표 화면을 미리 렌더링하고 이전에 실제 전송한 이미지에서 페이드한다. 상태 확인 100ms 주기와 애니메이션 시간은 별개다.

## 선택과 입력

수동 페이지 버튼은 자동 전환을 고정한다. 자동 버튼을 눌러 해제한다. 자동 모드에서는 설정 순서상 첫 앱 조건 일치를 선택하며, 없으면 기본 페이지를 선택한다. 짧은 앱 전환에는 250ms 지연을 적용한다. 문맥 관측 실패는 현재 페이지를 유지한다. 고정 여부와 페이지별 목록 배치를 저장한다.

페이지 전환은 눌림 바인딩을 무효화한다. 전체 목표 프레임 전송과 기존 키 해제가 끝나야 입력을 허용한다. 외부 focus/open/승인 실행은 아직 활성화하지 않는다.

## 전환

처음 연결할 때와 같은 페이지의 상태 갱신에는 애니메이션을 넣지 않는다. 사용자 페이지 또는 목록 하위 페이지를 바꾸면 설정된 페이드를 적용한다. 시간 기준으로 늦은 중간 프레임을 건너뛰고 목표 프레임을 정확히 전송한다. 새 목적지가 도착하면 기존 전환을 취소하고 마지막 실제 출력에서 이어간다.

잠금·종료는 애니메이션보다 우선한다. 중간 전송을 중단하고 기본 대기화면으로 복귀하며, 다시 활성화하면 최신 전체 화면을 보낸다. HID 전송 속도에 따라 실제 소요 시간은 달라질 수 있다.

## 검증

페이지 필터·구성 검증, 수동/자동 우선순위, 문맥 오류·지연, 저장 복원, 전환 중 키 해제, 느린 HID의 프레임 건너뛰기, 전환 취소와 종료를 자동 검증한다. 실제 장치 전환은 별도 진단으로 확인하고 실제 FPS 또는 부드러움은 관찰 없이 보장하지 않는다.
