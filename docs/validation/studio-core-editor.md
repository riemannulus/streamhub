## 자동 수직 검증

`packages/editor/core-editor.integration.test.ts`는 빈 Studio 문서에서 `홈`, `웹`, `미디어` 세 페이지를 구성하고 Studio HTTP API로 실행 중 Runtime에 적용한다. 가짜 플러그인이 받는 최종 15셀 프레임을 해시로 고정하고 다음을 검증한다.

- Firefox 앱, 웹사이트, 단축키, 텍스트, 미디어 동작이 각각 정확히 한 번 실행된다.
- 다음 페이지, 특정 페이지, 이전 페이지, 자동 전환 복귀가 올바른 페이지를 표시한다.
- 페이지 표시 버튼은 실행 효과나 불필요한 새 프레임을 만들지 않는다.
- 적용 직후, 동작 완료 뒤, 페이지별 최종 프레임이 승인된 SHA-256과 일치한다.

실행 명령:

```sh
bun test packages/editor/core-editor.integration.test.ts
bun run check
bun run streamdeck:plugin:check
git diff --check
```

## 사용자 보조 체크리스트

- [ ] `홈`, `웹`, `미디어` 페이지를 만들고 이름과 순서를 바꾼다.
- [ ] 앱 선택기에서 Firefox를 고르고 아이콘과 `Firefox` 라벨을 함께 표시한다.
- [ ] 웹사이트, 단축키, 텍스트, 미디어 버튼을 만든다.
- [ ] 이전, 다음, 특정 페이지 이동, `1 / 3` 페이지 표시를 배치한다.
- [ ] 버튼을 이동·복사하고 다른 페이지에 붙여 넣는다.
- [ ] `장치에 적용` 뒤 모든 시스템 동작이 물리 키 한 번당 정확히 한 번 실행되고 페이지 표시가 실제 페이지와 일치한다.

각 항목은 관찰 결과와 실패 시 재현 절차를 함께 기록한다. 이 체크리스트가 완료되기 전에는 M1의 **실기기 승인**을 주장하지 않는다.
